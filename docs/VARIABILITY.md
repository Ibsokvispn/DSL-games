## Espace des variantes
- taille de la grille (fixé au debut du jeu)
    - Carré de $x * x$
    - Autres formes ?
    - Effet des cases ?
- nombre de joueurs (fixé au debut du jeu)
- types de pions (fixé à la programmation du jeu / peut être modifié par le joueur au debut du jeu)
    - Nombre de pions
    - Caractéristiques des pions (forme, couleur, etc)
- regles de placement (fixé à la programmation)
- Nombre de phase de jeu 
- Regle de fin

## Configuration nommée (presets)

### Tic-Tac-Toe
- taille de la grille : 3x3
- nombre de joueurs : 2
- types de pions : X et O
- règles de placement : case vide, pion autorisé selon le joueur, nombre de pions à chaque tour = 1
- phase de jeu : 1
- règle de fin : aligner 3 pions

### Puissance 4
- taille de la grille : 7x6
- nombre de joueurs : 2
- types de pions : 2 couleurs différentes
- règles de placement : case vide, pion autorisé selon le joueur, nombre de pions à chaque tour = 1, pièce tombante
- phase de jeu : 1
- règle de fin : aligner 4 pions

### Quarto
- taille de la grille : 4x4
- nombre de joueurs : 2
- types de pions : 16 pièces différentes (forme, couleur, taille, remplissage)
- règles de placement : case vide, pion autorisé selon le joueur, nombre de pions à chaque tour = 1, le joueur choisit le pion pour l'autre joueur
- phase de jeu : 1
- règle de fin : aligner 4 pions
