# DSL-games

## Objectifs
Choisir une famille de jeux et l’analyser ; concevoir le métamodèle, la variabilité et une première syntaxe de votre DSL.

## Périmètre du projet
Nous avons choisi de créer un DSL pour les jeux d'alignement de pions sur une grille. L'objectif est de permettre la création de jeux similaires à Tic-Tac-Toe, Connect Four, Quarto et d'autres jeux où les joueurs doivent aligner des pions pour gagner.
